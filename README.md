# MyPlugin для nanoCAD BIM

MCP-сервер для работы с проектом из ИИ и тестовый стенд выгрузки иерархии в 3D.

В 0.3.2: демопроект Академпарка с переходом и надписью NANOSOFT.

## Загрузка

Скачать ZIP из [Releases](https://github.com/paulnsk/myplugin/releases), распаковать в постоянную папку.
В nanoCAD выполнить `NETLOAD` и выбрать **MyPlugin.dll**. Остальные файлы оставить рядом:
модуль соответствующего продукта (Электрика или ВК) подключается автоматически при запуске MCP.

Для автозагрузки: `APPLOAD` → «Автозагрузка» / «Содержание» → добавить **MyPlugin.dll**.

## MCP

| CAD-команда | Действие |
|---|---|
| `CW_MCP_START` | Запустить локальный MCP-сервер. |
| `CW_MCP_STOP` | Остановить сервер. |

URL для ИИ-клиента: **http://127.0.0.1:19426/mcp/**.
Через него можно создавать и редактировать проекты, оборудование, контуры и трассы;
в Электрике — расставлять светильники с расчётом освещённости, подключать оборудование и прокладывать кабели.
В ВК — настраивать водопотребление, назначать конфигурации труб, переносить стояки, вставлять арматуру и рассчитывать сеть.
Инструкции агент получает через `help_list` / `help_read`, начиная с `platform`.

Настройки: `Mcp/settings.json`. Логи: `C:\tests\ProjectStudioMcp\runtime`.
Сервер доступен только с этого компьютера, без токена. Пока агент рисует, проект вручную не менять.

## Стенд иерархии

Проект стенда создаётся в **Электрике**. Каждый запуск создаёт новый проект в `C:\test\AreaHierarchy3D`.

| CAD-команда | Действие |
|---|---|
| `CW_HIERARCHY_TEST_GENERATE_SAMPLE` | Создать демопроект с вложенными контурами, копиями, поворотами и высотами. |
| `CW_HIERARCHY_TEST_GENERATE_SAMPLE_ERROR` | Создать отдельный пример ошибки: два совпадающих контура. |
| `CW_HIERARCHY_TEST_GENERATE_ROTATIONS` | Три плана: ромашка зданий, закрученная башня и приближённый Академпарк с переходом. Только генерация; выгружать штатной командой 3D по иерархии. |
| `CW_HIERARCHY_TEST_GENERATE3D` | Ручная выгрузка в 3D с диалогом выбора контуров. Модель сохраняется, после выгрузки можно запустить `CW_HIERARCHY_TEST_VALIDATE`. |
| `CW_HIERARCHY_TEST_GENERATE3D_ALL` | Автоматическая выгрузка. Скрипт сам по очереди обходит все корни, показываемые в диалоге. Первый корень выгружается дважды — второй раз со смещением и поворотом. |
| `CW_HIERARCHY_TEST_VALIDATE` | Проверить сохранённые 3D-выгрузки текущего тестового проекта. Какие корни были выгружены, те и проверяются (для `CW_HIERARCHY_TEST_GENERATE3D_ALL` - все) |

Обычный порядок: создать стенд → выгрузить один пример или все → проверить.
Во время `GENERATE3D_ALL` не двигать мышь и не переключать окна: команда сама выбирает пункты формы.
В Г-образном примере вручную переместить выноску малой зоны внутрь территории перед выгрузкой.
