# ВК

Тип проекта — «Водоснабжение». Общие операции проекта, подоснов, контуров, оборудования и трасс остаются в platform. Модуль ВК подключается при CW_MCP_START в этом продукте.

Выбери нужную тему через help_read:

- watersupply-settings — нормативные водопотребители и назначение их приборам.
- watersupply-pipes — системы, сортаменты, трубы, стояки и арматура.
- watersupply-calculation — обновление и расчёт сети.

Для быстрого старта: проект → подосновы → этажи/маркеры → пауза для ручных помещений → водопотребитель → вводы/приборы/стояки → трубы → обновление → арматура → расчёт. Отчёты, аксонометрию и 3D запускает пользователь.

Типы и свойства ищи через types_search/types_describe, изделия — database_search. Значения из руководства назначаются явно, ID из примеров не переносятся в новый проект. Если шага нет в API или непонятен смысл свойства, уточни у пользователя.
