# Электрика

Тип проекта — «Электрика». Общие операции создания/редактирования остаются в platform.

Выбери нужную тему через help_read; читать все заранее не требуется:

- electrica-lighting — расчёт Ки и расстановка светильников в помещении, выключатели.
- electrica-network — шкафы, группы, аппараты, питание и электрический расчёт.
- electrica-cables — геометрические трассы, стояки, прокладка и изделия кабелей.

Для быстрого старта: новый проект → импорт подоснов → этажи/маркеры → пауза для ручного определения помещений → освещение → группы/подключения → трассы/кабели → питание/расчёт. Отчёты и 3D пользователь запускает сам.

Типы: ScsFloorContour, RoomContour, ElLighting, ElBoard, ScsTrace. Детальные свойства/enum — types_describe с query. ID и изделия бери из ответов, не угадывай.
