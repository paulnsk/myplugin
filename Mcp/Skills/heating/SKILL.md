# Отопление

Через app_context проверь продукт. Типы оборудования/трасс ищи types_search, свойства и связанные записи БД — types_describe с query. Не используй электрические классы.

database_search/get/import выбирают настоящее изделие; серия, категория и диаметр — разные признаки. objects_create размещает объект, traces_connect соединяет нативные точки, но не гарантирует правильную систему трубопроводов или успешный расчёт.

Полная отопительная сеть через MCP пока не проверена в CAD. Не выдумывай обязательные свойства и порядок работы; неподдержанную операцию сообщи пользователю.
