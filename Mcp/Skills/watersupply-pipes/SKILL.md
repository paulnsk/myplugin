# Системы и трубы

watersupply_systems_get даёт systemId и конфигурации. Для вводов, стояков и приборов systemId назначается через их свойства, найденные types_describe; подпись В1/Т3/К1 не заменяет ID системы.

database_search → database_get(fields=[...]) позволяет выбрать изделие и узнать свойство серии/сортамента. Для автоматического подбора диаметра импортируй весь сортамент: database_import(type,dbId,sourcePath,seriesProperty). Имя строкового свойства бери из types_describe(database=true), значение — из database_get; не используй просто общее название раздела. Без seriesProperty импортируется одно изделие. Ответ содержит проектный dbId выбранного изделия и count, не длинный список.

watersupply_configuration_set(items=[{systemId,dbId}]) возвращает configurationId для трубы DbPipe из БД проекта. После обычного traces_connect(type=TbTrace, ...) назначь конфигурацию созданным горизонтальным трубам через watersupply_pipes_apply(items=[{configurationId,ids:[...]}]). Эта операция заменяет нить трубы и её прежнюю конфигурацию; геометрия и связи сохраняются. Для новой трубы желательно делать это до следующего обновления сети. height в traces_connect — мм от нуля этажа.

Вводы, приборы и стояки создаются objects_create, этажи — contour_create с marker. types_search/types_describe показывают реальные типы и свойства продукта. Между вводами/стояками/приборами рисуются трубы; branch=true у traces_connect — врезка в горизонтальную трубу.

# Стояки и арматура

watersupply_stands_transfer(items=[{sourceFloorId,targetFloorId,ids:[...]}]) переносит выбранные стояки по маркерам, исходные остаются. Оба этажа должны иметь геометрически принадлежащие им маркеры. Совмещение с существующими стояками выполняется штатным сервисом по системе и положению; имя помогает выбрать среди близких. combine=false не совмещает. Результат проверь objects_find с планом и типом стояка.

watersupply_refresh создаёт/обновляет вертикальные подключения к приборам. objects_structure позволяет последовательно открыть детей прибора/стояка, узел подключения и участки TbVerticalPipePart. Через objects_get(fields=["HeightDown","HeightUp"]) прочитай высоты нужного участка.

watersupply_fixture_insert(items=[{segmentId,dbType,dbId}]) вставляет арматуру в середину вертикального участка; height при необходимости задаёт другую высоту в мм от нуля этажа, внутри участка. Изделие должно быть в БД проекта. Команда пока не вставляет насосы, водомеры и прочистки.

watersupply_stand_cut(items=[{id,end:"top"}]) обрезает верх стояка по подключениям; end="bottom" — низ. Ответ содержит итоговые высоты. Отсутствие изменения может означать, что подходящих подключений нет.
