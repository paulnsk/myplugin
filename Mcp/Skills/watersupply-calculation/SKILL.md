# Расчёт

У сети должен быть ввод, у водоразборных приборов — корректный UserIndex. До расчёта проверь настройки вводов через types_describe/objects_get: CalculationOption определяет вид расчёта; SecuredHead — гарантированный напор, параметры ГВС задаются отдельно. Диаметры, автоподбор и арматура настраиваются свойствами соответствующих объектов и нитей (objects_structure).

После геометрических правок вызови watersupply_refresh. Затем watersupply_calculate выполняет штатный расчёт по текущим настройкам вводов, без окна выбора систем. Возвращает страницу сетей, расход, требуемый напор, число ошибок и первые5 сообщений по каждой сети; limit ограничивает только ответ, не расчёт. Существующие расчётные документы продукта могут обновиться самим штатным расчётчиком.

Нулевое число сетей — не подтверждение корректности: проверь вводы, режим расчёта и водопотребителей. Ошибки исправляй по сообщениям и конкретным объектам, не заменяй проект новым. Если штатная операция требует пользовательского диалога, согласуй ручное действие. Отчёты и 3D отдельно не запускаются.
