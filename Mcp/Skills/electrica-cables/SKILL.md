# Трассы и кабели

Сначала логические связи (electrica-network), затем непрерывная геометрия трасс и настоящая прокладка. Нарисованная линия сама не назначает кабель/группу.

traces_connect принимает items:{planPath,type,firstId,secondId,height,waypoints?}. Для потолочной сети height обычно3000мм; монтаж светильников задаётся отдельно. waypoints — только промежуточные XY/XYZ, без концов. branch=true делает штатную перпендикулярную врезку узла в уже нарисованную трассу. objects_update.waypoints меняет маршрут; [] выпрямляет с сохранением концов.

Для переходов между DWG найди тип стояка через types_search, изучи свойства имени/высот. Создай пару на планах с одним именем и нужными высотами, подключи трассами. Этажи/маркеры задают совмещение планов, XY разных DWG не обязаны совпадать. После построения проверь фактическую маршрутизацию, не предполагай связность только по картинке.

electrica_cables_route(ids=[группы либо шкафы],replace=false) прокладывает по существующим трассам штатным алгоритмом. Не включай одновременно шкаф и его группы. replace=true разрешает удалить старую прокладку выбранных групп. Ответ — число необслуженных потребителей и до100 их ID; отсутствие пути требует проверить логические связи, разрывы/врезки/стояки и высоты.

electrica_cables_inspect(groupId,offset=0,limit=20) перестраивает/СОХРАНЯЕТ штатную кабельную модель и показывает страницу кабелей: cableOutId,segmentId,threads,lengthMeters,count,dbId. Это не чистое чтение, что отражено в аннотации инструмента. hasMore означает следующую страницу через offset+limit.

Импортируй ElWire. electrica_cables_bind принимает items:{groupId,dbId,cableOutId?,segmentId?,threads?}. Без фильтров назначает изделие всем кабелям группы; если части не хватает жил, отказывается до назначения. Для разных раскладок используй точные фильтры из inspect и отдельные элементы items. Команда сохраняет привязки и обновляет провода трасс. Число жил проверяется штатным предикатом; сечение/защиту подтверждай электрическим расчётом, не одним успешным bind.
