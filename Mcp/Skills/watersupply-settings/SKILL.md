# Водопотребители

watersupply_consumers_get(query=...) возвращает потребителей проекта и страницу нормативных типов текущей редакции СП. normDbId не является ID изделия БД оборудования.

watersupply_consumer_set(items=[{normDbId,count,hours}]) создаёт потребителя; для изменения вместо normDbId передай userId. Ответ userId назначается в свойство UserIndex водоразборных приборов через objects_create или objects_update. count — число людей/единиц по норме, hours — часов в сутки. Например, для административного здания из руководства: 100 и24.

Приборы создаются обычным objects_create: тип, УГО, изделие из БД проекта, монтажная высота и UserIndex. Нужные свойства и перечисления конкретного прибора уточняются types_describe(query=...). Монтажная высота — не координата Z.

Редакцию СП и исходные параметры расчёта берём из задания и текущих настроек проекта; нормативную пригодность по одному примеру не обещаем.
